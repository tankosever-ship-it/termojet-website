# Google Search Console — інструкція для termojet.com.ua

Документ для відповідальної особи. Мета: щоб Google **знайшов і проіндексував** сайт і **нову англійську версію (`/en`)**, яку щойно запустили. Без цих кроків уся нова SEO-робота просто чекатиме, поки Google випадково її помітить.

**Що вже зроблено технічно (робити НЕ треба):** sitemap з усіма UA+EN сторінками, hreflang-теги (мовні відповідники), серверні метадані. Ваше завдання — «підказати» це Google через GSC.

---

## Крок 0. Доступ до Search Console

1. Відкрити [search.google.com/search-console](https://search.google.com/search-console).
2. Перевірити, чи вже є ресурс (property) **termojet.com.ua**.
   - **Якщо є** — переходьте до Кроку 1.
   - **Якщо немає** — додати ресурс:
     - Тип **«Домен»** (рекомендовано) → ввести `termojet.com.ua` → Google дасть **TXT-запис**, який треба додати в DNS у кабінеті **ukrnames.com** (там же, де A-записи домену). Після додавання — «Підтвердити».
     - Або тип **«Префікс URL»** → `https://termojet.com.ua` → підтвердження через HTML-тег / Google Analytics (на сайті вже стоїть Google Tag Manager `GTM-P9DW9P6D`, тож може підійти верифікація через GA/Tag).

---

## Крок 1. Додати sitemap (найважливіше)

1. У лівому меню → **«Файли Sitemap»** (Sitemaps).
2. У полі «Додати файл Sitemap» ввести: **`sitemap.xml`** → **Надіслати**.
   (повна адреса: `https://termojet.com.ua/sitemap.xml` — там 768 сторінок, українські + англійські).
3. Через кілька годин/днів статус має стати **«Успішно»** і показати кількість виявлених URL.

---

## Крок 2. Прискорити індексацію ключових сторінок

Через **«Перевірка URL»** (рядок пошуку зверху) по черзі перевірити й натиснути **«Запросити індексування»** для:

- `https://termojet.com.ua/` (головна)
- `https://termojet.com.ua/en` (англійська головна — нова)
- 2-3 топ-товари (укр.), напр. `https://termojet.com.ua/catalog/nasosni-hrupy/ng-46-z-termokranom-1`
- ті самі товари в англ. версії, напр. `https://termojet.com.ua/en/catalog/nasosni-hrupy/ng-46-z-termokranom-1`
- `https://termojet.com.ua/en/catalog` (англ. каталог)

Це «поштовх» для Google. Решту сторінок він знайде сам через sitemap.

---

## Крок 3. Перевірити мовні версії (hreflang)

- Меню **«Індексування» → «Сторінки»** — стежити, щоб кількість проіндексованих сторінок зростала (мають зʼявитись і `/en/...`).
- Якщо в GSC є розділ **«Таргетинг за країною/мовою»** (International Targeting) — перевірити, чи немає помилок hreflang. Норма — помилок нема (теги вже стоять коректно).

---

## Крок 4. Що моніторити далі (протягом 1-4 тижнів)

| Розділ GSC | На що дивитись |
|---|---|
| **Сторінки (Індексування)** | Кількість проіндексованих росте; дивитись причини «не проіндексовано» |
| **Ефективність** | Покази/кліки. Фільтр по країні/запиту — зʼявляться англомовні запити (нова /en) |
| **Core Web Vitals** | Після оптимізації швидкості показники мають покращитись (перевіряти ~через 2-4 тижні — метрика накопичується) |
| **Зручність для мобільних** | Помилок бути не має |

---

## Що вважати успіхом

- Sitemap: статус «Успішно», ~700+ URL виявлено.
- Через 1-2 тижні: у «Сторінки» зростає число проіндексованих, зокрема `/en/...`.
- Через 2-4 тижні: у «Ефективність» зʼявляються англомовні запити й покази з інших країн.

## Якщо щось незрозуміло
Технічний бік (sitemap, hreflang, метадані) уже налаштований і працює. Питання по кабінету GSC — до розробника.
