## ⚠️ ВАЖЛИВО ПРО МЕТОД ПЕРЕВІРКИ

Дублі мікророзмітки були **тільки у відрендереному DOM** (після виконання JS) — саме це бачить Googlebot. Сирий HTML сервер завжди віддавав по 1 копії. Тому перевіряти треба інструментом, що **виконує JS**:

- GSC → Перевірка URL → «Переглянути проскановану сторінку»
- Google Rich Results Test — https://search.google.com/test/rich-results
- https://validator.schema.org
- Screaming Frog з увімкненим JavaScript Rendering (Config → Spider → Rendering → JavaScript)

Інструмент **без** рендерингу JS покаже стан, який був коректним і раніше.

## ✅ ВИКОНАНО

### [✓] 1. Дублі мета-тегів і мікророзмітки — усунено
- **Було:** теги інжектились двічі (сервер + клієнтський react-helmet); Googlebot після JS бачив по 2 копії: `title`, `description`, `canonical`, Open Graph, Twitter, а також подвоєні `Organization` / `Product` / `Breadcrumb`.
- **Стало:** сервер — єдине джерело SEO-тегів; клієнт більше нічого не дублює (`title` оновлюється через `document.title` без другого елемента).
- **Перевірено** (rendered-DOM, 11 сторінок усіх типів): по 1 копії кожного тега.
- Коміти: `63ba3e1`, `45db1f6`.

### [✓] 2. Мікророзмітка Organization — на всіх сторінках
- **Було:** після дедупу зникла зі сторінок поза списком серверної інжекції (`/reviews`, `/cart`).
- **Стало:** `/reviews` додано з повним набором (title/desc/self-canonical + Organization); решта роутів отримують Organization через SPA-fallback.
- **Перевірено:** Organization = рівно 1 на кожній сторінці (raw + rendered).
- Коміт: `e1d9b84`.

### [✓] 3. Ціни в грн у Product-схемі — виправлено для всього каталогу
- **Було:** 184 EUR-товари віддавали в схемі сире число EUR з підписом «UAH» → Google бачив ціну у ~52× нижчу (106 € → «106 грн»).
- **Стало:** сервер конвертує EUR→грн курсом **НБУ × 1.022** (як і сайт).
- **Перевірено:** 331/331 товарів — ціна в схемі = ціна на сторінці, `priceCurrency=UAH`. Розбіжностей нема.
- Коміт: `13e765a`.

### [✓] 4. Product-схема для товарів без ціни
- **Правило:** щойно у товару зʼявляється ціна > 0 — `Product` + `Offer` додаються автоматично (без ціни віддаємо лише Breadcrumb + Organization, бо Product без offers невалідний для Google).
- 3 товари, яким проставили ціну (НГ-81 = 31 250 грн, Wi-Fi RS = 21 192 грн, One = 13 049 грн), уже мають повну Product-схему.

### [✓] 5. (супутнє) Білий екран при перемиканні на PL/FR/DE — виправлено
- **Було:** вибір польської/французької/німецької давав білий екран (не було маршрутів для `/pl`, `/fr`, `/de`) — сторінки були недоступні.
- **Стало:** маршрути додано, усі мови відкриваються.
- Коміт: `da48a1a`.

## 🟡 ПОТРЕБУЄ РІШЕННЯ КОМАНДИ

### [ ] A. Сторінки PL/FR/DE — мінімальна SEO-розмітка
Сервер робить повний per-page рендер лише для UK та EN. Сторінки pl/fr/de мають Organization, але загальний title і canonical → UA-головна (Google їх консолідує, окремо не індексує). Це безпечно (без дублікатів контенту). Варіанти:
- лишити як є (консолідація), або
- canonical pl/fr/de → UA-еквівалент сторінки, або
- noindex для pl/fr/de, або
- повноцінна SSR-локалізація (окремий етап + переклади).

### [ ] B. robots.txt
Існує (`Allow: /`, `Disallow: /admin`, лінк на sitemap). Фінальні правила мала надати SEO-команда — чекаємо, якщо є зміни.
