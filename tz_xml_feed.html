Скрипт для description [опис]

Така ж логіка як і з назвою, але розширено. З title та description система визначає за якими пошуковими запитами показуватиме товарні оголошення.

Правила:
1. Найважливіша інформація — на початок.
2. Дублювати назву бренду кирилицею в дужках: Protherm (Протерм).
3. Включити: тип товару, бренд, модель, для чого призначений, розмір/потужність, матеріал, кількість, особливості, технічні характеристики.
4. Лаконічно — корисна інформація для покупця, без «води».
5. Завершувати фразою: «Замовити [назва] можна в інтернет-магазині Sofievka.»
